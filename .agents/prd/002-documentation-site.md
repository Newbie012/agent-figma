# PRD-002 - Documentation

## User need

A developer can understand, install, authenticate, and safely use `agent-figma` without reading the source repository, and without waiting for a website to be deployed.

## Behavior

- Ship the documentation as Markdown in `docs/`, readable on GitHub, in an editor, and in the published npm tarball.
- Cover installation, browser OAuth, personal access token fallback, the read-only boundary, command discovery, output formats, common agent workflows, and troubleshooting.
- Index every page from `docs/README.md`, so one file names the whole set.
- Generate `docs/reference/commands.md` from the command catalog, so the reference cannot describe a surface the CLI no longer has.
- Keep every other example aligned with `.agents/cli-api.md`.

## Refusals

- No documentation build step gates a release. The docs are files in the repository, not an application.
- No page is generated by hand from the catalog. `pnpm docs:write` writes the reference; a human writes the prose around it.

## Acceptance

- `pnpm docs:check` proves the command reference matches the catalog.
- A repository test proves every page links only to pages that exist, and that every command in the catalog appears in the reference.
- `npm pack` includes `docs/`.

## Deferred

A hosted documentation site with search, social cards, and LLM routes. The trigger is the CLI being published and someone asking for a link rather than a folder. Until then, [ADR-008](../adr/ADR-008-documentation-in-the-repository.md) records why the site was taken out.
