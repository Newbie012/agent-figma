Privacy

The OAuth relay is stateless. Because Figma requires a client secret, it exchanges authorization codes and refresh tokens in memory, then immediately discards them. It stores no tokens or Figma content.

The authorization grant returned to the CLI is encrypted to an ephemeral key generated on the operator's machine. Responses use Cache-Control: no-store. The CLI requests read-only scopes and sends Figma data requests directly from the operator's machine.

See the project documentation for the threat model and self-hosting instructions.
