# Changelog

Release notes are written as change intents when the change is made, and applied at release time by
`pnpm version -r`. The notes for each version live in `.changeset/changelogs/`, and the same text is
published as a GitHub prerelease under the matching `v` tag.

The package is on the `beta` channel: install it with `@beta`, and see
[`.agents/release.md`](./.agents/release.md) for how a release is cut.
